# 七个组件 / Seven Components

Version: **1.0.0**

七种可交互的微交互样本：长按确认、弹性开关、盖章确认、琴弦滑块、旋钮、里程表步进器与标本瓶进度。页面支持明暗主题、触控、鼠标和部分键盘操作，并尊重减少动态效果的系统偏好。

## 独立体验

https://gsvegetable.github.io/gongshui-open-source/seven-components/

## 嵌入

```html
<script src="https://gsvegetable.github.io/gongshui-open-source/seven-components/embed.js"></script>
```

也可以预先放置容器：

```html
<div id="seven" style="width:100%;height:560px"></div>
<script src="https://gsvegetable.github.io/gongshui-open-source/seven-components/embed.js" data-target="seven"></script>
```

加载器使用独立 iframe 隔离样式和脚本。调用容器上的 `gongshuiEmbed.destroy()` 可卸载嵌入内容。
