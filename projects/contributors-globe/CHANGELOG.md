# Changelog

## 1.3.0
- Remove the repository owner's personal contributor profile from the bundled dataset.
- Make the default contributor list empty.
- Keep submission UI hidden unless an explicit HTTPS submission page is configured.
- Document that the optional submission link only opens a user-provided page; no data is posted by the component.
- Add the generic `contributorsGlobe` embed API alias while retaining the legacy alias.

- Add one-line script-only embedding.
- Add options to hide pins, search, and control/flag buttons independently.
- Expose a ready promise and document API lifecycle.
- Clarify standalone reuse and asset/data licensing.

## 1.1.0
- Independent iframe loader and public API.
- Remove Gongshui website runtime dependencies.
