# 3_sy — 双轨卡片空间

**当前版本：0.19.0**

双轨卡片空间的 Web / Capacitor 实现，保留三种空间状态、双轨滚动、卡片翻面与触控交互。

在线预览：https://3-sy-workspace.vercel.app

## 本次更新

- 0.19.0：嵌入模式新增"按序号切换状态"接口 —— 宿主用按钮直接点名某个状态，不再依赖左右滑动。
  - 宿主发 `{ type: '3sy:preset', index }`，作品切到第 index 个状态（0 / 1 / 2）；
  - 每次切换完成后作品回 `{ type: '3sy:state', index }`，宿主据此高亮当前按钮；
  - 宿主发 `{ type: '3sy:state' }` 可以随时查询当前状态；
  - 原来的横向手势接口 `3sy:swipe` 保留，别的嵌入场景还能用。

- 0.18.0：新增嵌入模式 `?embed=1`，供宫水.com 首页把作品铺在作品网格底下当一层空间背景用。
  - 点卡片不再翻面，作品自带的搜索框与状态标签隐藏；
  - 底色透明，纵向滚动留给宿主页面（滚轮不吞、触摸 `pan-y`）；
  - 开放横向手势转发接口，宿主把拖动转发进来后左右切换照常工作。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

```bash
npm install
npm run build
npx cap sync android
npx cap open android
```
